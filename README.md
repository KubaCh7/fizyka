# Dynamika ruchu obrotowego bryły sztywnej

Interaktywna strona do nauki dynamiki ruchu obrotowego (I rok studiów / rozszerzona fizyka w liceum).
Całość to jeden plik `index.html`. Wystarczy otworzyć go w przeglądarce, nie trzeba niczego instalować.

Zawartość: mapa tematu, moment siły (widżet z drzwiami), moment bezwładności (kalkulator), II zasada dynamiki,
kinematyka z symulacją tarczy i wykresami, przykłady rozwiązywane krok po kroku, generator zadań z losowymi danymi
i podpowiedziami, najczęstsze błędy, quiz końcowy i ściąga do druku.

Biblioteki z CDN (potrzebny internet): KaTeX 0.16.11 (wzory) i Chart.js 4.4.1 (wykresy).
